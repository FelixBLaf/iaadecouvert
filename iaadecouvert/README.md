# IA à découvert — page balado (Équipe 5, SIA2020)

Projet étudiant fictif. Site statique hébergé sur Cloudflare Pages : https://iaadecouvert.felixbl.com

## Mettre à jour
Tout le contenu est dans `data.js` : descriptions, audio, miniatures, articles, transcriptions, sources, étiquette de transparence.
Déposer les fichiers dans `assets/` puis renseigner leur chemin dans `data.js`. Un champ vide affiche « bientôt disponible ».

## Exigences du cours (bonus)
- Mention « Projet étudiant fictif… » visible (bandeau + pied de page)
- Formulaire d'infolettre fictif : aucune donnée collectée
- Non indexé : `<meta name="robots">`, `robots.txt`, `_headers` (X-Robots-Tag)
